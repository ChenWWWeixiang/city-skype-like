操作指南

  • 左键拖拽：画道路 / 分区 / 拆除（选择模式下左键拖拽 = 转 3D 视角）
  • 右键 / 中键拖拽：平移　Q/E：旋转　滚轮：缩放　WASD：移动
  • 空格：暂停　1-5：速度　R 道路 Z 分区 S 服务 G 出入口 X 拆除
  • 画路默认自动吸附成直线，Shift 可画斜线，道路选项里能调曲率画弧线
  • 拖到已有道路附近会自动接成路口；路面随地形起伏，坡度超 15% 修不了路（绕山或挖隧道）
  • 道路可切成地面 / 高架 / 隧道：高架自动生成坡道做立体交叉，隧道从山体内部穿过
  • 水里修路自动架桥（有净空和桥墩），但桥上不能有路口，只能直行通过
  • 电力供水由发电厂 / 水塔按半径自动覆盖，不用铺管铺线，但要先有它们才会盖房子

城市怎么运转

  • 交通是核心：居民开车去工厂/商店上班，货车送货，居民消费后回家
  • 会真堵车：路口排队、等绿灯、车有碰撞体积不能重叠，堵了会回溯到上游
  • 堵车有后果：工业商业效率下降 → 商店倒闭 → 人口税收下降
  • 人口只来自「外来车辆 + 新生儿」；车只从家里车位诞生，开进建筑就是停车
  • 特种建筑（消防/警察/医院/学校/垃圾…）会带出对应的特种车辆，去处理火灾、犯罪、疾病、事故
  • 高速出入口建在地图边缘，连接城市与外界，没有它就没有外来人口
  • 市政维护实时扣钱，财政页可调结算步长，并显示净收支与人口增减

开局建议：点「一键建初级小城」看效果，或自己来：发电厂 + 水塔 → 主干道 → 住宅 → 商业/工业 → 出入口。
