操作指南

  • 左键拖拽：绘制道路 / 划分区域 / 拆除（选择模式下左键拖拽 = 3D 转视角）
  • 右键拖拽：平移　中键 / Alt+左键：平移　Q/E：旋转
  • 滚轮：缩放　WASD / 方向键：移动
  • 空格：暂停 / 继续　1-5：调整速度
  • R 道路　Z 分区　S 服务　G 出入口　L 车道　X 拆除　V 数据视图
  • 画路时默认自动吸附成水平/垂直直线（手抖也不会画歪）；按住 Shift 拖拽可画斜线，道路选项里还有曲率可以画弧线
  • 道路选项中可开启高架（自动生成坡道、可与其他道路立体交叉）
  • 电力与供水由发电厂 / 水塔按覆盖半径自动覆盖，无需铺设水管电线；但要先有它们，地块才会长出房子

城市怎么运转

  • 交通是核心：市民开车从住宅区去工业区/商业区上班，货车把工业品送到商业区，下班再去商业区消费后回家。
  • 两个时钟：城市时钟（人口、税收、昼夜）走得快，交通时钟（车速、信号灯、排队）接近真实时间 —— 所以你能真正看清车怎么开、怎么堵。
  • 会堵车：路口要排队、绿灯要等、车道有碰撞体积不能重叠，车多了就会排队回溯，一路堵到上游街区。
  • 堵车有后果：拥堵会拉低工业/商业效率 → 商业倒闭降级 → 人口与税收下降。修路、加宽、增设出入口都能缓解。
  • 高速出入口：建在地图边缘的道路上，城市与外界连通，外来人口更容易流入。
  • 人口只会「外来车辆 + 新生儿」产生：没有出入口的城市就没有新人；死亡与迁出（车开出城）会让人口减少。
  • 车不会凭空出现或消失：新车只在家里的车位诞生（居民买车 / 移民开车进城），车开进建筑就是「停进车库」，只有驶出城市与报废才会离开车队。
  • 特种车辆随特种建筑诞生：建消防站 -> 消防车出现，拆消防站 -> 消防车一起消失。特种设施有专属外形与光柱，一眼就能认出来。
  • 事件：城市会起火、发生犯罪、爆发疾病、出交通事故。都必须由对应的特种车辆真的开过去处理；没人管的话，房子会烧掉、会被罚款、病人会死亡、事故会一直堵着路。
  • 学校：提高教育水平（出生率与幸福度更高），校车在上下学时间出行。

开局建议：一键建初级小城 → 看交通面板 → 慢慢扩容。也可以自己来：发电厂 + 水塔 → 主干道 → 住宅 → 商业/工业 → 高速出入口。
